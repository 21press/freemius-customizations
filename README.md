# Freemius customizations

Public CSS and JS for 21Press Freemius store and account pages.

## URLs for Freemius

CSS:

```
https://cdn.jsdelivr.net/gh/21press/freemius-customizations@main/account.css
```

JS:

```
https://cdn.jsdelivr.net/gh/21press/freemius-customizations@main/account.js
```

jsDelivr caches aggressively. After you push changes, purge those URLs at [jsDelivr Purge](https://www.jsdelivr.com/tools/purge) so Freemius picks up the update.

Raw GitHub alternatives:

```
https://raw.githubusercontent.com/21press/freemius-customizations/main/account.css
https://raw.githubusercontent.com/21press/freemius-customizations/main/account.js
```
