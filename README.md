# Freemius customizations

Public CSS for 21Press Freemius store and account pages.

## CSS URL for Freemius

```
https://cdn.jsdelivr.net/gh/21press/freemius-customizations@main/account.css
```

jsDelivr caches aggressively. After you push CSS changes, purge that URL at [jsDelivr Purge](https://www.jsdelivr.com/tools/purge) so Freemius picks up the update.

Raw GitHub alternative:

```
https://raw.githubusercontent.com/21press/freemius-customizations/main/account.css
```
